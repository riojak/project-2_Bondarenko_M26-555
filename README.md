## Управление таблицами

В проекте можно создавать таблицы, удалять их и смотреть список уже созданных таблиц.

Для этого есть три команды:

create_table <имя_таблицы> <столбец:тип> ... — создаёт новую таблицу с указанными столбцами.

drop_table <имя_таблицы> — удаляет таблицу по её названию.

list_tables — показывает список всех созданных таблиц.

Для столбцов можно использовать три типа данных: int, str, bool.

При создании таблицы автоматически добавляется столбец ID:int, если его не указали самостоятельно.

### Пример работы

Создаём таблицу пользователей:

create_table users name:str age:int

Смотрим список таблиц:

list_tables

Результат:

users

Удаляем таблицу:

drop_table users

Если попробовать создать таблицу с уже существующим названием или указать неправильный тип данных, программа выведет сообщение об ошибке.

Все созданные таблицы сохраняются в файле db_meta.json, поэтому после выхода из программы они не пропадают.
